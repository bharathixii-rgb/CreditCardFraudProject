# Credit Card Fraud Detection Analysis

## Project Overview
This project analyzes credit card transactions to identify fraud patterns using SQL Server, Excel, and Power BI.

## Tools Used
- SQL Server
- Excel
- Power BI

## Key Features
- Fraud transaction analysis
- SQL data cleaning
- Interactive Power BI dashboard
- Excel pivot table analysis
- KPI reporting

## Dataset
- 284K+ transactions
- Fraud vs normal transaction analysis

## Dashboard Features
- Fraud percentage
- Transaction trends
- High value transaction analysis
- Time based analysis

## Skills Demonstrated
- SQL
- Data Analysis
- Data Visualization
- Power BI
- Excel
- Dashboard Development
